# Audit Reports

This directory contains task-owned, evidence-backed audit outputs. An `AUDIT`
task may write only the single report path named on its card; reports must
separate confirmed findings, source-backed risks, unverified runtime behavior,
and strategic hypotheses.

The READY task paths are `10-technical-seo.md`, `11-seo-content.md`,
`12-geo-ai-search.md`, `13-cro.md`, `14-brand-ux.md`, `15-qa-performance.md`,
`16-backlink.md`, and `67-backlink-authority.md`, the path assigned to Task 67 on
2026-09-14 when it took over the backlink audit scope from the held Task 16.
Existing reports, including the earlier
`11-keyword-strategy.md`, are retained as historical input. They are not a
license to claim a new audit was performed or to overwrite another task's work.
