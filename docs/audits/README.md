# Audit Reports

This directory contains task-owned, evidence-backed audit outputs. An `AUDIT`
task may write only the single report path named on its card; reports must
separate confirmed findings, source-backed risks, unverified runtime behavior,
and strategic hypotheses.

The task-owned report paths of the current Audit Wave are `10-technical-seo.md`,
`11-seo-content.md`, `12-geo-ai-search.md`, `13-cro.md`, `14-brand-ux.md`, and
`15-qa-performance.md`. `67-backlink-authority.md` is the path assigned to Task 67
on 2026-09-14, when it took over the backlink audit scope from Task 16. Task 16's
path `16-backlink.md` is named here for ownership only: that task is `ON_HOLD` and
must not be started, which corrects the earlier wording that listed it among READY
paths.
Existing reports, including the earlier
`11-keyword-strategy.md`, are retained as historical input. They are not a
license to claim a new audit was performed or to overwrite another task's work.
