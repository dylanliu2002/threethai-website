# Task 11 — SEO Content and Keyword Strategy Audit

## Goal

Map commercial and informational search intent to the current product,
application, knowledge, and answer architecture without creating cannibalization.

## Mode

Read-only audit. Do not edit files, browse the web, install packages, or commit.

## Inspect

- Product, application, article, answer, catalog, and localized content sources.
- Current route inventory and internal-link opportunities.
- Evidence quality, duplication, thin pages, and missing decision-stage content.

## Deliverable

Return:

1. Keyword-to-page map grouped by intent and funnel stage.
2. Existing-page keep/merge/expand recommendations.
3. Content gaps for product, application, knowledge, and buyer-answer pages.
4. Cannibalization and localization risks.
5. Prioritized implementation tasks with dependencies and evidence needs.

## Acceptance criteria

- Do not fabricate search volume or rankings.
- Label inferred keyword opportunities as hypotheses.
- Prefer strengthening useful existing routes before proposing new ones.
